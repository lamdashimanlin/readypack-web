# ReadyPack 网页版

**在线使用：** [打开 ReadyPack](https://lamdashimanlin.github.io/readypack-web/)

这是 ReadyPack 1.2.3 Preview 的网页版发布仓库，仅包含构建后的静态网页文件，不包含项目源码。

## 使用说明

- 在网页中选择文件或文件夹，在本机浏览器内整理并预览。
- 确认后可导出 ZIP；网页版的任务记录保存在当前浏览器中。
- 网页版不提供桌面版专属的 API 智能分类和整理助手。
